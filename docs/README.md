# Gross Poetry Systems

*Profoundly unfashionable since 2026.*

Control surfaces for uncertain machines: rigorous engineering and design for the probabilistic magic of intelligent systems.

---

## Catalog

A small, opinionated collection of primitives for agent-era work. Each tool is its own object — composable, restrained, intended to be picked up and used freely. They share an engineering sensibility, not a system architecture.

**Steel Cars** &nbsp;·&nbsp; *Agent harness primitive.* Composable single-agent runtime: routing, MCP, sessions, souls, vault, telemetry, sandbox backends. Unpainted on purpose. Steal one.

**Dijon** &nbsp;·&nbsp; *MCP primitive.* Put some Dijon on those docs. Amplifies any corpus it serves — docs, codebases, data, knowledge — into a clean MCP surface that agents can address.

**Tempor Codex** &nbsp;·&nbsp; *Planning.* Planning server for repo-grounded work: context, policy, routing, cost, and handoff contracts. The deliberation layer between intent and execution.

**Sea Noise** &nbsp;·&nbsp; *Memory.* Personal cognition layer on Obsidian. Captures the ambient input of an intellectual life and reflects its shape back. Local-first, audience-of-one, mirror not assistant.

**Whomst Valence Test** &nbsp;·&nbsp; *Evaluation.* Liveness battery for agents. Tells you whether a system is actually agentic, or just conversational.

**Dummy** &nbsp;·&nbsp; *Secrets.* Secrets by indirection. Pointers in your `.env`; plaintext appears only at the point of use. *Be a dummy.*

**Bag-dat** &nbsp;·&nbsp; *Skills.* Git as a shared skill registry. Fans skills into Claude, Cursor, Codex, and Gemini discovery paths.

**Chops** &nbsp;·&nbsp; *Fleet ops.* Self-hosted agent fleet management — budgets, approvals, domains. The control room.

**cable-run** &nbsp;·&nbsp; Schema, model, and workflow contracts. AI wiring that doesn't sprawl through the app.

## Notes on practice

- Local-first, human-first. The individual is primary.
- Choose the most durable tool, language, or pattern for the job. Minimize dependencies where possible.
- Respect center of gravity where it matters: publish into the ecosystems where the audience and collaborators already are.
- Governance is part of UX, not a layer above it.
- Ship the canonical implementation. Adoption is by example.
- Share only what survives both tests: durability in use, and a sensible open-source collaboration surface.
- Subtract until restraint shows. Features that don't earn their keep are removed, not deferred.
