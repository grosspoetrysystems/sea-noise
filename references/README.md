# References

Imported source material from the current live vault.

These files are here to support the rewrite as:
- architecture references
- product references
- skill/spec references
- prompt/behavior references

They are **not** active runtime code.

## Structure

- `docs/`
  - rewrite plan
  - product vision
  - system architecture
- `skills/`
  - skill manifest
  - skill definitions used as command/spec references
- `prompts/`
  - canonical Claude instructions and command surfaces

## Intended use

Use these files when rebuilding specific parts of the runtime.

Do not assume that every imported behavior should survive unchanged.
